# IDB Open Data (data.iadb.org)
#
# Everything here is open to read: dataset pages, resource pages, file downloads,
# the data catalog and the API. The data is free to reuse under CC BY,
# and every dataset has a DOI you can cite.
#
# How to use the API:
#   Find datasets:        https://data.iadb.org/api/3/action/package_search?q=remittances&fq=type:dataset
#   Get one dataset:      https://data.iadb.org/api/3/action/package_show?id=latin-macro-watch-dataset
#   Query a table:        https://data.iadb.org/api/3/action/datastore_search?resource_id=<id>&limit=100
#   Full catalog (DCAT):  https://data.iadb.org/catalog.ttl  (also .rdf and .jsonld)
#   API documentation:    https://docs.ckan.org/en/2.11/api/
#
# Good to know:
# - Search results include datasets, indicators and data portals.
#   Add fq=type:dataset to get datasets only.
# - Table queries only work on files marked datastore_active: true in the dataset record.
#
# Questions or bulk access: opendata@iadb.org
